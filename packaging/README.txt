카카오톡 빠른 로그인 0.1.0 (Windows x64)

[사용 방법]
1. KakaoQuickLogin.exe를 실행합니다.
2. 처음 한 번만 카카오톡 비밀번호를 입력하고 저장합니다.
3. 이후에는 같은 EXE를 실행하면 됩니다.

[비밀번호 변경]
- Shift 키를 누른 상태로 KakaoQuickLogin.exe를 실행합니다.
- 또는 명령 프롬프트에서 KakaoQuickLogin.exe --reset 을 실행합니다.

[저장된 비밀번호 삭제]
- 명령 프롬프트에서 KakaoQuickLogin.exe --forget 을 실행합니다.

[보안]
- 비밀번호는 서버나 클립보드로 보내지 않습니다.
- Windows DPAPI로 암호화되며 현재 Windows 사용자만 복호화할 수 있습니다.
- 암호화 파일: %LOCALAPPDATA%\KakaoQuickLogin\password.dat

[주의]
- Windows 10/11 x64와 Windows용 카카오톡을 지원합니다.
- 추가 인증이나 보안 확인은 직접 완료해야 합니다.
- 카카오톡 화면이 변경되면 새 버전이 필요할 수 있습니다.
- 이 프로그램은 카카오 또는 카카오톡의 공식 제품이 아닙니다.
